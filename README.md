# Ejercicios de programación en Java
## Semana 2 - Cálculo de áreas en Java
Este ejercicio calcula el área de tres rectángulos utilizando variables de tipo `double`.

Los cálculos realizados son:

- 10.5 × 20.4
- 5.5 × 40.3
- 101 × 101

Luego, los resultados se muestran por consola.
